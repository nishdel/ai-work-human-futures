# Changelog

## 3.0.0 — 11 October 2026

- Preserved the original design, 15 domains, six technology presets, four social presets, chart engine and 240 seeded paths.
- Added concrete slider endpoints, live interpretations, accessible glossary links, preset explanations and custom/restore state.
- Replaced the personal starter profile with 17 occupational archetypes plus custom tasks, optional preparation answers, transparent scoring and alternative-role comparison.
- Added a curated historical evidence snapshot and source attribution; removed unverified headline benchmark numbers.
- Made profile sharing explicitly opt-in and imported state strictly validated. Valid v2 assumptions migrate with a visible notice.
- Yielded computation in batches and cached results; profile/social changes avoid global simulation.
- Corrected non-attainment date quantiles and sensitivity arithmetic; bumped the model version. Continuous baseline curves are unchanged.
- Kept self-contained offline and GitHub Pages builds. Automated evidence collection remains deferred.
