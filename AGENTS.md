# Contributing

Preserve the plain HTML/CSS/JavaScript design, deterministic model and offline build. Read MODEL.md before changing arithmetic. Inspect Git status and preserve unrelated work.

Use an existing, verified OmniLAB route for bounded substantive implementation when available. Declare relevant files, expected output and independent acceptance checks; run one local inference at a time within the current resource budget. Do not install or substitute models, change inference settings or modify development infrastructure for this application. After a bounded retry, record the concrete blocker and complete suitable work directly.

Local model output is a proposal. The supervising contributor reviews patches, verifies sources, runs tests and owns acceptance. Distinguish local-originated work, repairs and direct implementation; do not invent savings. Contributors without OmniLAB can use the ordinary Node workflow.

Run `npm run build` and `npm test`. Use existing Playwright/browser installations for offline file, repository-subpath, mobile emulation, keyboard, imports and privacy checks where available. Record unavailable checks honestly.

Never commit private input, personal profiles, machine paths, credentials, screenshots with visitor data, local-agent logs or handoff packages. Audit the staged diff and history before public release. Keep model, career and evidence versions explicit. New evidence must not silently alter assumptions or visitor state.
